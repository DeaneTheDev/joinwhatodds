How it works

The maths, done for you

Most competitions are fine. A few are genuinely brilliant value. WhatOdds does the boring part — reading every ticket price, discount tier, bundle and cashback offer — so you only see the ones worth your time.

1

Scan every site

WhatOdds automatically reads the live listing on each competition site it covers — prices, tickets sold, discount tiers, bundles, the lot.

2

Work out the real cost

Not the list price — the actual cost to buy the whole ticket pool at the best rate the site currently offers, cashback and bundles included.

3

Alert only on genuine value

If that real cost is good against the prize, you get an alert, ranked Good through Fantastic. If it's not, you hear nothing. No noise.
