# joinwhatodds

The public landing page for [WhatOdds](https://discord.gg/YmT2ju4CY) — a Discord server that scans UK
prize competition sites for genuinely good-value odds.

Deployed via GitHub Pages. `CNAME` points it at `joinwhatodds.co.uk` once the domain's DNS is configured
(see repo settings → Pages, and the domain registrar's DNS records).

Kept deliberately separate from the [whatodds-py](https://github.com/DeaneTheDev/WhatOdds) scanner repo,
which stays private.
